# 洁净室施工技术交底自动生成系统（CleanDoc）— 简历案例说明（压缩版）

> 300 字版，适配简历项目栏；初稿完整版见对话记录（未落盘）。

**1. 业务痛点**：洁净室施工技术交底依赖专家手工编写，耗时长、质量参差，正文引用无出处、无法审计追责。

**2. 解决方案**：自研双路检索+融合生成管线。规范路复用知识图谱系统（Neo4j 图谱 + ChromaDB 向量 + BM25 + BGE 重排 + DeepSeek），项目路自建项目知识库（500 字符切片 + 向量/BM25 混合召回 + RRF 融合），自动生成六章节交底；正文 [n] 引用全部可点击，溯源至规范文件及项目资料「文件名+段落」级，形成可审计证据链。

**3. 成果**：冒烟测试 5 项全绿；2 份示例资料切片 26 条、双路各召回 8 条，单次生成 2335 字交底；模型常驻后检索 <2s；覆盖 478 节点/417 关系的 HVACR 专业本体。

**4. 技术栈**：Python · Streamlit · Neo4j · ChromaDB · BM25/RRF · BGE-large-zh-v1.5 · BGE-Reranker · DeepSeek API · Docker（GPU）。

**5. 未来应用场景**：扩展全专业规范库与条文级溯源，沉淀多项目知识资产，演进为企业级技术交底知识中台。
